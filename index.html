📋 Identidad
¿Qué es? La interfaz principal para hablar con Claude (web, escritorio, móvil)
Interfaz conversacional con sandbox Linux (Ubuntu 24) para ejecución de código aislada. Filesystem se reinicia entre sesiones.
 Contenido que se muestra en un panel separado al lado del chat (páginas, apps, diagramas)
Archivos renderizados en el cliente según extensión (.html, .jsx, .md, .mermaid, .svg, .pdf). Entorno React restringido con librerías predefinidas.
 Paquetes de instrucciones que hacen a Claude mejor en tareas específicas
Directorios con SKILL.md (YAML frontmatter + markdown), scripts opcionales, templates y recursos. Carga lazy bajo demanda. Estándar abierto Agent Skills.
 Herramienta de línea de comandos para desarrolladores que trabaja directamente en tu proyecto
CLI agéntico vía npm (@anthropic-ai/claude-code). Requiere Node.js. Acceso directo al filesystem local, shell, git, y toolchain completo.
 Versión de Claude Code para no-programadores, dentro de la app de escritorio
Arquitectura agéntica idéntica a Claude Code (Claude Agent SDK) con ejecución en VM containerizada. Monta carpetas del usuario en el sandbox. Soporta sub-agentes paralelos.
 Protocolo estándar abierto que conecta a Claude con apps y datos externos
Protocolo sobre JSON-RPC 2.0, inspirado en LSP. Arquitectura Host → Client → Server. Primitivas: Tools, Resources, Prompts. Donado a la Linux Foundation (AAIF) en dic. 2025.
